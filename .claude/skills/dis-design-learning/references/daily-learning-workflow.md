# DIS日次収集ワークフロー

## 標準頻度

1日3件。LP、バナー、Webサイトを各1件ずつ扱う。各媒体で候補が基準未達または取得不能なら、その媒体だけ無理に選ばずスキップする。

## 実行順

1. 参照元レジストリからLP、バナー、Webサイトの公開ソースを読む。
2. 各媒体で最大5候補を比較し、選定基準13/18点以上で、重複でない1件を選ぶ。
3. 掲載元詳細URLと実ページURLを記録し、公開条件・利用条件を確認する。
4. LP／WebはPC・SP、バナーは実寸画像を、許される範囲で取得する。
5. 新規専用のDropboxフォルダーに正本、軽量プレビュー、メタデータを保存する。
6. DISの全セクション分析、9軸、注釈、改善案、再現手順を作る。
7. 媒体別Notionライブラリーに新規ページだけを作る。既存ページを更新しない。
8. 出典、選定理由、未確認、権利上の注意を記録して完了報告する。

## 守ること

- 既存のDropbox、Notion、CBS、過去分析を上書き・移動・削除しない。
- アクセス制御を回避せず、ギャラリーを一括取得しない。
- ロゴ、人物、写真、コピー、価格、実績値は再利用対象にしない。
- NotionまたはDropboxの書込みが失敗・不明なら、重複再試行前に既存の新規成果を確認する。
