# DIS参照元レジストリ

## 読み取り条件

- 公開ページだけを読む。ログイン、課金壁、Bot対策、ダウンロード制限を回避しない。
- 現行の利用条件と画面上の制限を確認し、不明または自動取得が禁止されている場合は取得しない。
- 出典の詳細URL、実ページURL、タイトル・ブランド、取得日時、出典区分を残す。
- LPはPC・SP、バナーは公開サイズ・媒体を確認する。
- ギャラリーを一括ダウンロードしない。選んだ候補だけを低頻度で扱う。
- 保存物は内部の研究用とし、固有の写真・人物・ロゴ・コピー・価格・実績値は再利用・再配布しない。
