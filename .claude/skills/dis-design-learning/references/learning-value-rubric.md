# 学習価値（learningValue 0〜1）の評価基準

一覧画像（サムネイル）から確認できる範囲で評価する。見えないことは推測せず、理由に「未確認」と書く。

| 観点 | 高い（0.8〜1） | 低い（0〜0.3） |
|---|---|---|
| 構成の明快さ | 情報の優先順位が一目で分かる | 何を伝えたいか不明、情報が散らばる |
| 独自性・再発見性 | 既存のライブラリーにない型・技法 | 既存の登録と同じ型の繰り返し |
| 再現可能性 | 自社の制作（Canva/Photoshop/Elementor）で原則を応用できる | 専用のイラスト・撮影素材に依存し、原則が取り出せない |
| 実務との近さ | 中小の事業・店舗・採用など、案件で使う場面に近い | 大型IP・特殊な用途で応用しにくい |
| 資料の十分さ | 全体が見える（長尺はPC/SPが取得できる） | 画像が小さい、情報が欠ける |

- 0.5 は「未評価」の既定値。評価したら必ず理由を書く（`learning.json` の `reason`）。
- 画像が取れない候補（空欄）は、評価しない（0.5のまま）。
- 権利・利用条件が不明な候補は、評価とは別に、分析の「権利・未確認事項」に書く。
