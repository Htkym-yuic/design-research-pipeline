## 3. 発見（directional — 生データはCSVに）

数字には必ず次のいずれかを付ける。

- **N + 95%信頼区間**（例: 「23% ±5pp、95% CI ≈ 18-28%、n=278」）
- 揮発性の高いGitHub件数に対する明示的な **directional floor** ラベル
  （例: 「数十万件規模、total_countは揮発的、ファイル数でリポジトリ数ではない」）

裸のパーセンテージ禁止。code-search件数への偽の精度禁止。
