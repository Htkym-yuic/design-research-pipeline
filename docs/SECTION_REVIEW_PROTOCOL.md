# セクション画像の「画像を見る確認」手順（厳しめ）

目的: 全LPについて、`02_セクション別` の切り出し画像が、**正しい種類（FV・悩み提起・ベネフィット・フッター…）に振り分けられているか**、**全体画像に見えているのに、切り出されていない種類がないか**を、画像を見て確認する。
状態: 手順の案（2026-11-21）。確認は Mac の Claude Code で行う（API は使わない）。Dropbox・Notion は変更しない。

## 1. 準備（Mac）
```bash
cd ~/design-research-pipeline-auto && git pull
npm run dis:section-review-prep -- --from 1 --to 10     # 10件ずつ。出力先: ~/dis-review-sheets（Dropboxの外）
```
LPごと・端末ごとに、2枚のシートができる。
- `LP-nnnn_<PC|SP>_full.jpg`: 全体画像を縦に区切って横に並べた図（上から下への流れが、左から右に並ぶ）。
- `LP-nnnn_<PC|SP>_sections.jpg`: 切り出し画像の一覧。各画像の上に `#番号` と種類コード（`K01`=FV … `K16`=ナビ）。
- `LP-nnnn.manifest.json`: `#番号` → ファイル名・種類フォルダ。

種類コード: K01 FV／K02 悩み提起／K03 解決策／K04 商品紹介／K05 特徴／K06 ベネフィット／K07 実績／K08 流れ／K09 CTA／K10 FAQ／K11 フッター／K12 その他／K13 比較／K14 料金／K15 会社情報／K16 ナビ。

## 2. 確認の進め方
- **1会話で、1〜2LPだけ**（画像が重いため）。`~/dis-review-sheets` のシートを、Claude Code に読ませる。
- 端末（PC／SP）ごとに、①全体シートで、ページの構成（上から、どんな役割のまとまりがあるか）を、まず書き出す。②切り出しシートの各 `#` を、全体の構成と照らして判定する。③全体にあるのに切り出しにない種類を、`missing` に書く。
- 画像から読み取れないことは、推測しない（`unreadable` にして理由を書く）。

## 3. 判定の基準（厳しめ）
| 判定 | 条件 |
|---|---|
| ok | 画像の内容の**主役が1つの役割**で、付いている種類と一致。切れがなく、隣の領域の混入が**画像の高さの約5%以下**（縁・影・数十pxの帯程度） |
| wrong_kind | 内容が、付いている種類と違う（例: 悩み提起の画像が `K06 ベネフィット` に入っている）。`correctKind` に正しい種類を書く |
| mixed | 1枚に、**2つ以上の役割**が入っている（例: 実績と CTA が1枚）。切り直しが必要 |
| bad_crop | 見出しや本文が途中で切れている／隣のセクションの混入が**約5%を超える**（見出し・画像・文字が読める程度に入っている）／余白だけ |
| split | 1つのセクションが、**2枚以上の画像に分かれている**（どの画像も、単体では不完全）。`note` に、同じ組の `#番号` を書く。切り直し（結合）の候補 |
| duplicate | 同じ内容の画像が、同じ端末・同じ種類に複数ある |
| unreadable | 画像が小さい・壊れている等で、判定できない |

- **FV**: ページ最上部の、キービジュアル＋主コピー＋**最初の CTA ボタンまで**（2026-11-21 決定）。FV の直下に続く最初の CTA（ボタン・申込・資料請求の帯）は、FV に含める（`K09 CTA` には入れない）。FV と最初の CTA が別の画像に分かれていたら `split`（結合の候補）。ナビだけ・ヘッダだけは FV にしない（`K16`）。
- **FVなしのLP**（2026-11-21 決定）: ページの最上部が、すでに商品紹介・特徴など、FV にあたらない内容から始まるLPもある（例: LP-0245）。このときは、`structure` の先頭に「FVなし」と書き、`01_FV` に入っている画像は、**内容で判定し直す**（`wrong_kind`＋正しい種類。ほかの画像と内容が重なれば `duplicate`）。FV がないことは、`missing` にしない。
- **フッター**: 最下部のリンク集・コピーライト。直前の CTA 帯は含めない（`K09`）。
- **不足（missing）**: 全体シートで、はっきり見えるのに、対応する切り出しがない種類だけ。LPに本来ない種類は、不足にしない。
- 混入が約5%以下のものは `ok` にして、`note` に「上端に前セクションの縁」などと書く（#番号ごとに、同じ基準で揃える）。
- **全体シートの最下部**（フッター・著作権表記・会社情報など）が見えないときは、`note` に「全体画像が最後まで撮れていない可能性」と書く（撮り直し候補）。

LPごとに、`data/lp-section-review/LP-nnnn.json`（リポジトリ内）に書く。
```json
{
  "lp": "LP-0001",
  "reviewedAt": "2026-11-21",
  "devices": {
    "PC": {
      "structure": ["FV", "悩み提起", "ベネフィット", "実績", "CTA", "フッター"],
      "sections": [
        { "index": 1, "file": "LP-0001_…_PC_01_FV.png", "assignedKind": "01_FV", "verdict": "ok", "note": "" },
        { "index": 2, "file": "…", "assignedKind": "06_ベネフィット", "verdict": "wrong_kind", "correctKind": "02_悩み提起", "note": "悩みのチェックリスト" }
      ],
      "missing": [ { "kind": "10_FAQ", "evidence": "全体シートの5列目にQ&Aが見える" } ]

  }
}
```

## 5. 集計
```bash
npm run dis:section-review-summary
```
判定ごとの件数、問題のあるLP、直す候補の一覧（`data/lp-section-review-fixes.csv`）が出る。**ファイルの付け替え・切り直し・撮り直しは、一覧を確認してから、別の手順で行う**（この手順では、何も動かさない）。

## 6. セクション画像が無いLPを作る（切り出し）
対象: 全体画像はあるが、セクション画像が無い端末（例: LP-0227・0228、LP-0029 SPのFV）。**範囲は、全体画像を見て決める**。

1. シートを作る（全体シートには、元画像の y 座標の目盛り（赤い点線、500pxごと）と、各列の y 範囲が入る）。
   ```bash
   npm run dis:section-review-prep -- --lp LP-0227
   ```
2. Claude Code で、`~/dis-review-sheets/LP-0227_PC_full.jpg`（SPも）を見て、**ページの上から順に、セクションの範囲（y0〜y1、元のpx）と種類**を決め、`data/section-cut-plans/LP-0227.json` に書く。
   - 基準は、本書の「判定の基準」と同じ。FV は「最初のCTAボタンまで」。1つのセクションを2枚に分けない（split にしない）。1枚に2つの役割を入れない（mixed にしない）。
   - 切れ目は、背景色や余白の境目に置く。見出しや文字の途中で切らない。隣の領域の混入は、約5%以下。
   - ページの最下部（フッター）まで、取りこぼしなく入れる。最下部が空白や途中切れなら、`note` に書く。
3. 計画を検証する（何も保存しない）。範囲・種類・順番・重なり・最下部の取りこぼしを、チェックする。
   ```bash
   npm run dis:cut-sections -- --plan data/section-cut-plans/LP-0227.json
   ```
4. 確認して、保存する（新規のみ。すでにあるファイルは、スキップ）。
   ```bash
   DIS_ENABLE_WRITES=true npm run dis:cut-sections -- --plan data/section-cut-plans/LP-0227.json --apply
   ```
   出力: `02_セクション別/<NN_種類>/<PC|SP>/<LP-nnnn_名前>_<PC|SP>_<NN>_<種類>.png`（NN はページ上の順番）。

計画の書式:
```json
{ "lp": "LP-0227", "folder": "LP-0227_タニカのあまざけ",
  "devices": { "PC": { "sections": [ { "y0": 0, "y1": 1800, "kind": "01_FV", "note": "" } ] }, "SP": { "sections": [] } } }
```
